# Code of Conduct

## Our Commitment

We want this project to be welcoming, respectful, and safe for everyone.

## Expected Behavior

- Be respectful and constructive.
- Focus discussions on ideas and technical outcomes.
- Assume good intent and communicate clearly.
- Accept feedback professionally.

## Unacceptable Behavior

- Harassment, hate speech, or personal attacks
- Doxxing or sharing private information
- Abusive, discriminatory, or threatening language
- Repeated disruptive behavior

## Enforcement

Project maintainers may edit/remove comments, close issues/PRs, or block users
for behavior that violates this Code of Conduct.

## Reporting

Report issues privately to the repository maintainer through GitHub.
