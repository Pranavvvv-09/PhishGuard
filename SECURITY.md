# Security Policy

## Supported Scope

This project is intended for defensive phishing detection and analysis.

## Reporting a Vulnerability

If you discover a security issue in PhishGuard:

1. Do not open a public issue with exploit details.
2. Report it privately to the repository maintainer via GitHub.
3. Include:
   - affected file/module
   - impact
   - reproduction steps
   - suggested fix if possible

We will acknowledge and triage reports as quickly as possible.

## Responsible Use

This tool must be used for defensive security work only. Do not use it to
support phishing, impersonation, or other malicious activity.
